# Glosario del Proyecto

Clase: Plantilla o molde a partir del cual se crean objetos. 
Define los atributos y métodos que tendrán las instancias creadas.

Objeto: Instancia concreta de una clase que posee un estado (datos)
 y un comportamiento (métodos).

Encapsulamiento: Mecanismo de POO que protege y oculta los detalles 
internos de una clase, limitando el acceso a sus datos únicamente a 
través de métodos públicos (`getters` y `setters`).

Tipo Primitivo: Tipo de dato básico integrado en Java (`int`, `boolean`, `double`, etc.) 
que guarda el valor directamente en memoria sin comportamiento de objeto.

Clase Wrapper: Clase de Java (`Integer`, `Boolean`, `Double`, etc.) que envuelve a un tipo 
primitivo para permitir su manejo como un objeto, facilitando el uso de valores `null` y colecciones.
